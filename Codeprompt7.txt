## 8. API INTEGRATION

Use actual backend endpoints.

Requirements:
- Centralized API client.
- JWT authorization.
- Secure refresh-token handling.
- Proper 401 and 403 handling.
- Error handling.
- Loading states.
- Pagination.
- Form validation.
- Upload progress where supported.

Do not hardcode fake complaint records as production data.

Mock data may only be used in clearly identified development/demo mode.

Never put backend secrets or provider API keys in frontend environment variables.

Do not store long-lived sensitive credentials in localStorage.

Follow the backend's actual authentication and refresh-token contract.

- Run backend tests.
- Build frontend.

- Run lint checks.
