# CIVICX — PREMIUM COLOURFUL UI/UX MASTER DESIGN PROMPT

## PRODUCT IDENTITY

Product: CivicX  
Tagline: Your Neighbourhood, Connected.

Design CivicX as a premium, colourful, modern neighbourhood super app.

The application should combine local news, events, civic complaints, shops, product discovery, workers, doorstep services, advertisements and community announcements into one unified experience.

The UI must be visually impressive, easy to use and mobile-first.

## 1. BRAND COLOUR SYSTEM

Use this exact starting colour palette consistently.

| Purpose | Colour | Hex |
|---|---|---|
| Primary Navy | Deep Navy | #142B55 |
| Primary Blue | Electric Blue | #2878F0 |
| Secondary | Teal | #13B8A6 |
| Accent | Coral | #FF765E |
| Events | Purple | #8B5CF6 |
| Complaints | Red | #EF5350 |
| Shops | Green | #13A889 |
| Product Finder | Amber | #F5A623 |
| Workers | Dark Teal | #0D9488 |
| Advertisements | Pink | #E85D91 |
| Background | Light Grey | #F3F6FB |
| Card Background | White | #FFFFFF |
| Main Text | Charcoal | #202B3C |

Use light tinted backgrounds behind coloured feature icons.

Use gradients selectively:
- Navy to Electric Blue for hero sections.
- Teal to Green for local discovery highlights.
- Purple to Pink for event highlights.

Do not use gradients everywhere. Maintain a clean and premium appearance.

## 2. MAIN APPLICATION NAVIGATION

- Home

## 4. LOCAL NEWS

Use blue as the main colour.

Design:
- News feed cards.
- Large image previews.
- Headlines.
- Locality labels.
- Contributor details.
- Published time.
- Share, comment and like actions.

Categories include traffic, roads, water, electricity, sanitation, public safety and community announcements.

AI-generated content must be reviewed and approved by the user before publication.

## 5. EVENTS & CIVICX MOMENTS

Use purple as the main colour.

Design:
- Event discovery cards.

- Date and location badges.
- Event categories.
- Photo/video galleries.
- Event detail pages.

Include festivals, concerts, rallies, sports, movie celebrations and community gatherings.

- Shop cover images.

## 19. VISUAL QUALITY

The interface must have:

- Premium modern design.
- Beautiful colourful feature cards.
- Consistent colour coding.
- High-quality local imagery.
- Clear typography.
- Soft shadows.
- Rounded corners.
- Balanced whitespace.
- Smooth interactions.
- Responsive layouts.
- Light theme initially, with dark theme support where practical.

Avoid excessive gradients, random colours, overcrowded layouts and inconsistent components.

## 20. DEVELOPMENT RULES

Before implementation, inspect the existing CivicX frontend, framework, routes, components, styling system and available APIs.

Reuse the existing architecture.

Do not rewrite the entire project.

Do not invent working APIs.

Use mock data only where backend APIs are unavailable, and clearly separate it from real API integration.

Do not break existing functionality.

## FINAL EXPECTATION

Deliver a complete, colourful, premium and responsive CivicX interface.

The final experience should look like one unified neighbourhood super app, not separate disconnected applications.
