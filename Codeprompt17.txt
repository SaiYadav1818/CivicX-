# ✦ CIVICX
## MASTER UI/UX DESIGN & DEVELOPMENT PROMPT

**Product:** CivicX – Your Neighbourhood, Connected.  
**Design Goal:** Modern • Premium • Minimal • User-Friendly • Mobile-First

---

# 01. 🌟 PRODUCT VISION

Design CivicX as a modern neighbourhood super app that brings citizens, local businesses, workers, events and community information together in one platform.

Users should be able to discover what is happening around them, report local problems, explore businesses, find workers and connect with their neighbourhood.

**Core concept: One neighbourhood. One platform. Multiple possibilities.**

# 20. ✨ UI QUALITY CHECKLIST

The final interface must have:

- Responsive mobile, tablet and desktop layouts.
- Beautiful and consistent typography.
- Realistic sample content.
- Proper image sizing.
- Clear visual hierarchy.
- Functional navigation.
- Loading and error states.
- Empty-state illustrations or messaging.
- Accessible controls.
- Form validation.
- Subtle interactions.
- No unnecessary animations.
- No overcrowded screens.
- No inconsistent design patterns.

Every screen should feel like part of one application.

# 21. ⚙️ DEVELOPMENT INSTRUCTIONS

Before implementation:

1. Inspect the existing CivicX frontend.
2. Identify its framework and styling system.
3. Inspect existing routes and components.
4. Reuse the existing architecture.
5. Inspect available backend APIs.
6. Identify missing backend functionality.
7. Separate real API integration from mock data.

Do not rewrite the entire application.

Do not invent APIs and claim they work.

Do not break existing modules.

Do not introduce unnecessary dependencies.

Use mock data only where APIs are not yet available, and clearly separate it from production data.
